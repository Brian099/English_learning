## 二、调参过程（关键证据）

初版按常规做法开启 VAD（Silero，默认阈值 0.5），结果严重失真。三次对比：

| VAD 设置 | 总词数 | S01E06（186s） | 说明 |
|---|---|---|---|
| 阈值 0.5（默认） | **308** | 72 词 | 大量对白被整段切掉 |
| 阈值 0.25 | 497 | 182 词 | 明显改善 |
| **关闭** | **603** | 190 词 | 最终采用 |

**原因**：这批素材音乐/音效连续铺底（静音占比仅 0–8%），Silero VAD 把"音乐+对白"整段判为非语音，直接从输入里切走了。VAD 本意是防幻觉，在这里反而成了主要的信息损失源。

**另一个反直觉的发现**：`no_speech_prob` 在音乐铺底时完全不可信。实测正常对白段的该指标可达 **0.92**（S01E06 的 "Let's help!"、"Push!" 等），若按常规阈值 0.6 过滤，会丢掉一半以上的真实对白。最终把它放到 0.98，等于基本不启用。

**结论**：音乐铺底的儿童动画，**幻觉过滤不能靠 VAD 和 no_speech_prob**，只能靠压缩比 + 去重 + 套话黑名单。这一点与通用 Whisper 调参经验相反，必须写进设计。

## 四、质量评估

**没有发现幻觉垃圾。** 全文通读一遍，没有出现"请订阅频道""字幕由 XX 提供"这类训练数据残留，也没有复读机式重复。

**抽样正确性**（人工对照画面字幕）：

| 识别结果 | 实际应为 | 类型 |
|---|---|---|
| `A big nut!` | 待核（可能是 seed） | 名词混淆 |
| `Wren!` | 可能是 `Run!` | 同音误识 |
| `I'm going to eat you, B.` | 应为 `Bumblebee` | 截断 |
| `Good night, Rain.` | 大小写问题 | 标点 |

整体可读性很高，作为**索引、分级、出题的数据源**完全够用；作为给孩子阅读的教材需要人工校对。

**两个需要留意的现象**：

1. **长段无标点**：关闭 VAD 后，音乐段会把多句合并成一段（如 S01E06 开头 20 秒一段），导致该段无大小写和标点。对检索和出题无影响，但做 SRT 字幕时观感差。
2. **WPM 差异极大**（60–138）：说明各集对白密度差别很大。

## 五、衍生价值：用转写数据给内容打标签

这批数据已经能算出几个有用的指标：

| 指标 | 用途 |
|---|---|
| 语音占比 52%–99% | **磨耳朵适配度**：占比低的集"看"的成分大于"听"，不适合音频模式 |
| WPM 60–138 | 语速分级，慢速集适合入门 |
| 词数/语音分钟 | 对白密度，判断一集能提供多少语言输入 |
| 603 词 / 9 集 | 平均 67 词/集，词汇量可控，适合做生词表 |

**初步判断**：`皮普 S01E04（VLOG，138 WPM）` 和 `S01E02（朋友帮助朋友，117 WPM）` 是语言密度最高的两集，适合做听力材料；`S01E03 甜蜜的陷阱（语音占比 52.6%）` 音乐占比大，更适合"看"。

## 六、下一步建议

1. **人工校对 1–2 集**（对着画面双语字幕），确认错误率是否可接受 → 决定要不要换 `medium.en`
2. **跑全量**：按 8.6× 实时，900 分钟素材本机约 1.7 小时，NAS 夜间 4–5 小时
3. **做分级**：用 603 词的样本先验证词表算法（Dolch / Oxford 3000），再上全量
4. 把 `speech_s` 写回后端，作为完成判定的分母（替代视频总时长）
